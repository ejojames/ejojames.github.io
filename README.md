# Ejo James - Portfolio Website

This is the source code for my personal portfolio website hosted on GitHub Pages. Built as a fast, responsive single-page site to showcase my projects, current technical interests, and certifications.

Features
Warm Dark Palette: Custom CSS variables, warm amber accents (#e5a93b), and Space Grotesk typography.

Responsive Layout: Sticky left sidebar on desktop displays with smooth scrolling and clean mobile fallback.

Zero Dependencies: Pure HTML5 and CSS3 without frameworks, heavy libraries, or build toolchains.

Tech Stack
HTML5: Semantic tags, clean element hierarchy, and inline SVG graphics.

CSS3: Flexbox, CSS Grid, media queries, and root design tokens.
